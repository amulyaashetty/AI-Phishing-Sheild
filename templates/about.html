About AI Phishing Shield

Project Mission

AI Phishing Shield is an intelligent, educational tool designed to detect and prevent phishing attacks. Built for cybersecurity students and professionals, it combines multiple detection techniques including keyword analysis, URL inspection, sender verification, attachment scanning, and AI-powered pattern recognition.

How It Works

When you submit an email for analysis, the system runs it through six independent detectors:

  • Keyword Detector: Identifies suspicious words like "verify", "urgent", or "confirm password"
  • URL Analyzer: Checks for shortened URLs, IP addresses, and suspicious domains
  • Regex Patterns: Detects common phishing patterns and suspicious phrases
  • Sender Verification: Analyzes sender address for spoofing and homograph attacks
  • Attachment Scanner: Checks for dangerous file types and suspicious characteristics
  • AI Analysis: Uses machine learning (Mistral model) for intelligent reasoning

Risk Scoring

Each detector produces a score, which are weighted and combined into a final risk assessment:

Low Risk (0-30)

Likely legitimate email

Moderate (30-60)

Review before opening

High Risk (60-80)

Likely phishing

Critical (80-100)

Definite threat

Key Features

  • Multi-detector pipeline: Combines 6 independent analysis methods
  • AI-powered analysis: Uses local Mistral LLM for intelligent reasoning
  • No API keys required: Runs completely locally with Ollama
  • Comprehensive scoring: Get detailed breakdowns of each detector's assessment
  • History tracking: Save and review all previous analyses
  • Educational focus: Learn how each detection technique works
  • Modern UI: Clean, intuitive interface for easy use

Important Disclaimer

AI Phishing Shield is an educational tool designed to help learn about phishing detection. While it uses advanced detection techniques, no system is 100% accurate. Always use this in conjunction with proper email security practices:

  • Verify sender email addresses carefully
  • Never click links from unsolicited emails
  • Check URLs by hovering before clicking
  • Be cautious with attachments from unknown senders
  • Report suspicious emails to your email provider
  • Use email authentication protocols (SPF, DKIM, DMARC)

Getting Started

  1. Go to the Email Detector tab
  2. Paste your email content (include From, Subject, and body)
  3. Click "Analyze Email" to run detection
  4. Review the risk score and detector analysis
  5. Check the recommendations for next steps
  6. View your analysis history anytime
